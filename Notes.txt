Order Mikroservisi için Services altýna Order kalsörü ekle.Bu mikroservis de "Onion Architecture" kullanýcaz.
Order içine Core,Infrastructure,Presentation klasörleri ekle
Core klasörü içine 2 tane class library ekle(MultiShop.Order.Application,MultiShop.Order.Domain)
Infrastructure klasörüne Class library ekledik.(MultiShop.Order.Persistence)
Presentation klasörüne api projesi ekledik.(MultiShop.Order.WebApi)

Features klasörüne CQRS ve Mediator klasörleri ekledik.
CQRS klasörüne CQRS Design Pattern daki klasör yapýsýný oluþturdu.CQRS içinde:
